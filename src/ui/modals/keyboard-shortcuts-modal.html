Keyboard Shortcuts

ctrl / ⌘command + s Save notes as plain text
alt / ⌥option + s Save notes as PDF
alt / ⌥option + c Copy notes to system clipboard
ctrl / ⌘command + , Preferences
ctrl / ⌘command + k Open list of Keyboard Shortcuts
ctrl / ⌘command + shift + o Insert Unicode symbol
ctrl / ⌘command + shift + delete Delete notes
ctrl / ⌘command + b Bold the selected text
ctrl / ⌘command + i Italicize the selected text
ctrl / ⌘command + u Underline the selected text
ctrl / ⌘command + shift + x Strikethrough the selected text
ctrl / ⌘command + . Superscript (rich text notes)
ctrl / ⌘command + shift + l / e / r / j Align left / center / right / justify (rich text notes)
ctrl / ⌘command + \ Clear formatting (rich text notes)
ctrl / ⌘command + shift + 7 / 8 / 9 Bulleted / numbered / checklist (rich text notes)
alt / ⌥option + v Start / stop voice typing
ctrl / ⌘command + alt / ⌥option + ← / → Switch to the previous / next note tab
