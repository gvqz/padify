Future feature list
	Right now the app is very much in beta, and numerous new features are being improved and added. Despite this, we need to make sure that the classic plain note is well fixed, as that's the main feature. 

Improvements in the very far future
	
	- add drawing pad
	- add tasks/notes (based on apple reminders/tasks)	
	- detect dates and suggest to add them to calander 
	- Heavily improve PWA experience
		- save notes to users computer documents folder, use .padify format, which will be able to load all note types and drawing
		- push notifications for timers, reminders, etc 	
		- automatically open .padify files

	Note: .padify format might not actually make it to the actual app, compare benefits/disadvantages 

Visual overhauls:
	- cloud sync/share
	- settings menu
		- have settings based on each note type(classic, markdown, RTN, etc)
	- Statistics menu + add more fun statistics, the current visual menu looks bad. Clicking on the text should rotate the stat (ex it says 1961 characters but when I click that text it switches to 340 words etc)
	- Music menu: this also needs an archecture overhaul/work. Currently the alwaysdata server hasn't been setup so it has not been tested and very much likely doesn't work as intended, delay changing this until specifically instructed with the words "music menu"
	- unicode menu. I don't know what to do with this right now, it's a bit broken and looks bad.


about /markdownreports
	markdownreports\drawingpad.md: not super important, just remember that Excalidraw will be used for canvas, could also require to download PWA for this(so that nothing needs to be sent to the server and just stays on the device instead)
	markdownreports\tasks.md: not super important either, will be based on apple reminders/tasks and will have a lot more features

the rest of the features will be made as "tools" (a tool icon in the topbar + popup) if they are made
	markdownreports\teleprompter.md: may not be added, and would likely have less features
	markdownreports\text-diff.md: also unlikely to be added, would be very far in the future(compare between two of the same note type or HISTORY(like google docs)) users would have option to include formatting and other things to be ignored when comparing the texts
	markdownreports\text-tools.md: likely to be added, but much differently. No sample text, and would be based on the note text and not directly affect it(only copy the extracted/). No wrap, no encode/decode. Find and replace will not be added in this, as it will be a whole seperate feature.
	markdownreports\voice-notes.md: may be added as a PWA only feature(far in the future), save voice recordings as it transcribes.
